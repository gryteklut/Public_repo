<Quiz id="s8-1">
A user should see a published desktop and nothing else in the subscription. Which role fits?

- [x] Desktop Virtualization User on the application group
- [ ] Owner on the subscription
- [ ] Desktop Virtualization Host Pool Contributor
- [ ] Virtual Machine Contributor on every session host

Desktop Virtualization User is the role for using desktops and apps. Host Pool Contributor and Virtual Machine Contributor are management roles. Owner is far too broad.

[Source: Built-in Azure Virtual Desktop roles](https://learn.microsoft.com/en-us/azure/virtual-desktop/rbac)
</Quiz>

<details class="study-collapse">
<summary>Study this topic</summary>

Split admin roles the same way the resources split: host pool, application group, workspace, and session hosts. Local group membership on the session host is a separate decision (who is a local admin inside Windows). The exam asks for both Azure RBAC and the rights on the session host.

</details>

<Quiz id="s8-2">
Administrators must reach a session host to troubleshoot it. Users connect only through Azure Virtual Desktop. What do you use for the administrators?

- [x] Azure Bastion or just-in-time VM access, with no public RDP port
- [ ] An inbound NSG rule for TCP 3389 from Any
- [ ] RDP Multipath as the admin jump host
- [ ] A Conditional Access exclusion for all administrators and a public IP

Bastion and just-in-time access are the study-guide options for administrative access. User sessions do not need a public RDP port. App Control for Business (WDAC) and Controlled Folder Access protect what runs on the host. Defender for Cloud, Defender Antivirus, and Defender for Endpoint are the other security layers, and they are not interchangeable.

[Source: Azure Bastion](https://learn.microsoft.com/en-us/azure/bastion/bastion-overview)
</Quiz>

<details class="study-collapse">
<summary>Study this topic</summary>

Network security for the session host subnet is NSGs, user-defined routes, and Azure Firewall, including the required outbound endpoints. Trusted Launch and confidential VMs are host security types from the infrastructure skills. Do not treat Defender Antivirus definition updates as a substitute for Defender for Endpoint onboarding.

</details>
