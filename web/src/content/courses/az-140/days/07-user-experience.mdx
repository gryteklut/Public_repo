<Quiz id="az140-d7-q1">
Users must print to a local printer and map a local drive into the session. Where do you set that for the whole host pool?

- [x] RDP properties on the host pool
- [ ] The session host image definition in Azure Compute Gallery
- [ ] A Conditional Access grant control
- [ ] The FSLogix VHDLocations value

Host pool RDP properties control redirection (drives, clipboard, printers, cameras) for connections to that pool. The image does not store the user's client devices. FSLogix stores the profile.

[Source: RDP properties](https://learn.microsoft.com/en-us/azure/virtual-desktop/customize-rdp-properties)
</Quiz>

<details class="study-collapse">
<summary>Study this topic</summary>

Lab 2 configures RDP properties after it adds session hosts and reviews load balancing. Intune or Group Policy still configures settings inside Windows, such as Universal Print or a timeout that you also want enforced if someone signs in another way. Know which layer the question is pointing at.

</details>

<Quiz id="az140-d7-q2">
Personal desktops are deallocated at night. You want a user's virtual machine to start when that user connects. What do you enable?

- [x] Start VM on Connect, with permission for the Azure Virtual Desktop service to start the virtual machine
- [ ] A breadth-first load-balancing algorithm
- [ ] RDP Multipath
- [ ] An Office container

Start VM on Connect starts a stopped virtual machine at connection time. The service principal needs a role that can start the VM, such as Desktop Virtualization Power On Contributor, on the resource group that holds the session hosts. Load balancing does not power on a deallocated personal desktop by itself.

[Source: Start VM on Connect](https://learn.microsoft.com/en-us/azure/virtual-desktop/start-virtual-machine-connect)
</Quiz>

<details class="study-collapse">
<summary>Study this topic</summary>

Lab 2 assigns that role to the Azure Virtual Desktop service principal while it configures Start VM on Connect. Scaling plans (day 9) are the schedule-based control for pooled capacity. You can use both, and they answer different questions.

</details>

<Quiz id="az140-d7-q3">
Disconnected sessions are holding pooled capacity all afternoon. What do you set?

- [x] Session time limits so idle and disconnected sessions end
- [ ] A larger FSLogix container
- [ ] Private Link on the workspace
- [ ] Trusted Launch on the session host

Session time-limit properties end sessions that are idle or disconnected. That returns the slot to the pool. Storage size and Private Link do not sign the user out.

[Source: Configure a time limit policy](https://learn.microsoft.com/en-us/azure/virtual-desktop/autoscale-create-assign-scaling-plan)
</Quiz>

<details class="study-collapse">
<summary>Study this topic</summary>

Set the limits in host pool properties or with policy, and tell users that a disconnected session will not stay forever. Combine this with load balancing. A disconnected session still counts toward the max session limit until it ends.

</details>

<Quiz id="az140-d7-q4">
A user must always return to the same session host. Which configuration is that?

- [x] A personal host pool, with the desktop assigned to that user
- [ ] A pooled host pool with breadth-first and FSLogix
- [ ] A RemoteApp application group
- [ ] Cloud Cache with two file shares

Personal host pools have a desktop assignment. You assign and unassign the user when they change roles. Pooled plus FSLogix gives the same profile on any host, which is a different requirement. RemoteApp publishes an application, not a dedicated desktop.

[Source: Personal desktop assignment](https://learn.microsoft.com/en-us/azure/virtual-desktop/configure-host-pool-personal-desktop-assignment-type)
</Quiz>

<details class="study-collapse">
<summary>Study this topic</summary>

Automatic assignment can give the next free personal desktop to the first user who connects. Direct assignment pins a named user. Unassign the desktop before you hand it to someone else, and decide whether the profile is local to that virtual machine or still in FSLogix.

</details>
