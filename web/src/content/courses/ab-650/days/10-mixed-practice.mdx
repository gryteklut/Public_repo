<Quiz id="ab650-d10-q1" shuffle={true}>
You have limited study time left and you want to spend the most of it on the largest AB-650 domain. Which weighting should drive that choice?

- [x] Govern and secure about 40–45 percent, AI services about 35–40 percent, tenant and workloads about 20–25 percent
- [ ] Tenant and workloads about 40–45 percent, govern and secure about 20–25 percent, and AI services unmeasured
- [ ] Endpoint and Cloud Apps about 40–45 percent, Copilot about 10 percent, and identity work covering the rest
- [ ] Each of the three domains about one third, so extra days on agents do not change the plan

The study guide puts govern and secure first, then AI services, then tenant and workloads. Hybrid sync depth, full endpoint administration, and Cloud Apps are not where that weight sits, and the domains are not equal. [Study guide for Exam AB-650](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ab-650)
</Quiz>

<Quiz id="ab650-d10-q2" shuffle={true}>
Copilot quoted a salary file. The person who asked is allowed to open that file today. Copilot must stop using the file, and the person must still open it. What should you change?

- [ ] The user's authentication methods, so Copilot can no longer sign in as them
- [x] Discovery or the search scope for that file, not a new identity design
- [ ] Entra Connect sync, because the file is being grounded through hybrid identity
- [ ] A Global Administrator role for the user, so they can opt out of grounding

The user can already open the file, so the symptom is grounding and discovery, not a missing identity design. Changing authentication methods, adding Entra Connect, or granting Global Administrator does not take that file out of Copilot while leaving it open for the user.
</Quiz>

<Quiz id="ab650-d10-q3" shuffle={true}>
Five administrators hold standing Global Administrator and use it only a few times a month. What is the better design?

- [ ] Add a sixth standing Global Administrator so one person is always signed in
- [ ] Replace the directory role with a sensitivity label named Global Administrator
- [ ] Put a report-only Conditional Access policy in front of every admin sign-in and stop there
- [x] Make the role eligible in PIM and have them activate it only for the task that needs it

Standing privilege is the problem PIM is meant to shrink. An eligible assignment is activated for the task and then ends. Another standing admin makes the problem larger. A sensitivity label is not a role. Report-only mode does not remove the standing assignment, and it would not block the sign-in either.
</Quiz>

<Quiz id="ab650-d10-q4" shuffle={true}>
You need a measured phishing exercise for the sales team and follow-up training for people who click. Which product does that?

- [x] Attack simulation training in Defender for Office 365
- [ ] A Purview retention policy whose default subject line mentions phishing
- [ ] Copilot web search pointed at a known phishing URL
- [ ] Network connectivity insights for the office where sales sits

Attack simulation training runs the campaign against the group you choose and assigns training from the outcome. Retention, web search, and network insights do not send the exercise or track who clicked.
</Quiz>

<Quiz id="ab650-d10-q5" shuffle={true}>
Passport numbers must be blocked when someone pastes them into a Copilot prompt. You already know who has been using Copilot. What is the control that enforces the block?

- [ ] The Copilot usage report, filtered to people who typed a passport number
- [x] A DLP policy that includes the Copilot location and detects that sensitive info type
- [ ] DSPM for AI, with the recommendation left as a suggestion and no policy behind it
- [ ] The Teams meeting policy that allows transcription

DLP is what can block the sensitive prompt. The usage report and DSPM for AI tell you about activity and posture. They do not enforce this block on their own. A meeting transcription setting does not inspect Copilot prompts.
</Quiz>

<Quiz id="ab650-d10-q6" shuffle={true}>
An agent is built and waiting. Nobody in the company should use it until an administrator approves publication. Which control is that approval?

- [ ] Giving the builder standing Global Administrator so they can self-approve
- [ ] Enabling Microsoft 365 Backup on a mailbox created for the agent
- [ ] Adding a Safe Links exception for the URL where the agent is hosted
- [x] The agent registry review that publishes, rejects, or blocks the agent

The registry is the approval gate before publication. A standing Global Administrator role, Backup, and a Safe Links exception do not review or publish the agent.
</Quiz>

<Quiz id="ab650-d10-q7" shuffle={true}>
Choose two. A confidential site appears in Copilot for people who can already open it, and a regional help desk must manage only the users in one country. Which two actions match those two problems?

- [x] Restrict discovery of the site, or narrow permission if those people should not open it
- [ ] Turn off every Conditional Access policy so Copilot can reindex the site
- [ ] Install Entra Connect and filter the SharePoint site by the user's country
- [x] Scope the help-desk role to an administrative unit that contains that country

Discovery or permissions is the Copilot fix. If people must keep opening the file, restrict discovery rather than deleting their access. The help desk is limited by scoping the role to the administrative unit. Disabling Conditional Access and adding Entra Connect do not solve either request.
</Quiz>

<Quiz id="ab650-d10-q8" shuffle={true}>
Yesterday's SharePoint site must be restored for the project team. Contracts must also be kept for seven years. Which pairing is right?

- [ ] Backup keeps the contracts for seven years, and a retention label restores yesterday's site
- [ ] Attack simulation restores the site, and DSPM for AI is what keeps the contracts
- [x] Microsoft 365 Backup restores the site, and a retention label or policy keeps the contracts
- [ ] Service health restores the site, and company branding is what keeps the contracts

Backup is the operational restore of the deleted site. Retention is the control that keeps the contracts for the compliance period. Swapping those two tools, or substituting attack simulation, DSPM for AI, service health, or branding, misses one of the jobs or both.
</Quiz>
