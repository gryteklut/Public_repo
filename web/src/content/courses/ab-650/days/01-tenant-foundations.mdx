<Quiz id="ab650-d1-q1" shuffle={true}>
Contoso wants the company logo and a custom background on the Microsoft 365 sign-in page. The street address and technical contact must stay in the organizational profile. What should you configure for the logo and background?

- [ ] Microsoft 365 admin center, Settings, Org settings, Organization profile
- [x] Microsoft Entra admin center, Company branding for the sign-in page
- [ ] SharePoint admin center, Settings, then the site theme and logo
- [ ] Exchange admin center, Organization, then Organization sharing

Entra company branding paints the sign-in page, including the logo, background, and theme. The organizational profile in the Microsoft 365 admin center stores the address and technical contact, and it does not theme sign-in. SharePoint branding applies to sites. Exchange organization sharing does not control the sign-in page.
</Quiz>

<Quiz id="ab650-d1-q2" shuffle={true}>
Northwind added contoso.com, and the domain now shows as verified. Mailboxes still cannot send or receive as @contoso.com. What should you do next?

- [ ] Assign every mailbox a Microsoft 365 Copilot license before mail routing can start
- [ ] Create a Conditional Access policy that requires MFA for Exchange Online
- [x] Add the Exchange DNS records, including MX, and finish email setup for the domain
- [ ] Turn on Microsoft 365 Backup and restore the domain from a backup point

Verification only proves you own the DNS zone. Exchange still needs the service records, especially MX, before that domain carries mail. A Copilot license does not publish DNS. Conditional Access can challenge a sign-in, and Backup restores mailbox content. Neither one makes a new domain routable.
</Quiz>

<Quiz id="ab650-d1-q3" shuffle={true}>
Fabrikam must give Microsoft 365 Copilot to about 2,000 people in Finance and remove it when they leave that department. What should you configure?

- [ ] Turn on pay-as-you-go and do not assign any per-user Copilot license
- [ ] Assign the Copilot license to the Finance shared mailbox so the department inherits it
- [ ] Let each person buy Copilot from the Microsoft 365 self-service store
- [x] Assign the Copilot license to a group that contains the Finance users

Group-based licensing adds and removes the user license with group membership. Pay-as-you-go can cover some consumption charges, and it does not replace the Microsoft 365 Copilot license for the people who use Copilot. A shared mailbox is not a person using Copilot. Self-service purchase does not stay aligned with department membership.
</Quiz>

<Quiz id="ab650-d1-q4" shuffle={true}>
The operations team must be emailed when Exchange Online or Microsoft Teams has a service incident, without watching the admin center all day. What should you configure?

- [x] Service health notification settings in the Microsoft 365 admin center
- [ ] A Microsoft Purview DLP policy that emails the team on credit-card matches
- [ ] An attack simulation campaign that emails the operations team each week
- [ ] Company branding custom text that mentions the current service incident

Service health in the Microsoft 365 admin center is where you review incidents and configure notifications. A DLP policy notifies on sensitive-data activity. Attack simulation sends a training exercise. Company branding is static sign-in text, not a live health alert.
</Quiz>

<Quiz id="ab650-d1-q5" shuffle={true}>
Choose two. Litware needs two outcomes: staff must see the company logo at sign-in, and the help desk must be emailed when a Microsoft 365 service is degraded. Which two configurations meet those outcomes?

- [ ] Publish a sensitivity label so the logo is stored as classified content
- [x] Configure company branding in the Microsoft Entra admin center
- [ ] Enable Restricted SharePoint Search so the logo is hidden from Copilot
- [x] Configure service health notifications in the Microsoft 365 admin center

Company branding supplies the sign-in logo. Service health notifications send the degradation mail. A sensitivity label classifies content and does not theme sign-in. Restricted SharePoint Search limits which sites search and Copilot can use. It does not place a logo on the sign-in page.
</Quiz>

<Quiz id="ab650-d1-q6" shuffle={true}>
Users in one office report poor Teams calls. The Microsoft 365 service health page shows no incident. You need evidence about that office's path to Microsoft 365. What should you review?

- [ ] Defender for Office 365 alerts for malware detections in that office
- [x] Network connectivity insights in the Microsoft 365 admin center
- [ ] DSPM for AI recommendations about Copilot prompts from that office
- [ ] The organizational profile, to confirm the office street address

Network connectivity insights describe how a location reaches Microsoft 365. A clear service health page does not prove the office network is healthy. Defender alerts, DSPM for AI, and the street address in the org profile do not measure that path.
</Quiz>

<details class="study-collapse">
<summary>Study this topic</summary>

Sign-in branding is Entra company branding. The organizational profile, service health, and network connectivity insights live in the Microsoft 365 admin center. A verified domain still needs workload DNS, such as MX, before mail works. Group-based licensing assigns Copilot to people. Pay-as-you-go does not replace that user license.

</details>
